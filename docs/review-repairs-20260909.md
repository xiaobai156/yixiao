## 正式入口与输出

`single --formal` 使用完整配置集合校验，空结果、缺站、多站、重复站、期数不符、只读成功和配置不符全部在写入前拒绝。`commit_formal_single` 保留兼容名称，但必须显式传入 `expected_sites`；定点调用方应改用 `commit_targeted_formal_single`。

`retry --formal` 只抓失败清单准确匹配的站点，以正式模式签发结果后做定点合并，不再把局部结果送入全量输出。无法匹配或清单身份变更不扩大复抓范围。失败复抓只更新该站失败诊断，保留此前已验证的成功行和缓存；成功复抓仅更新选中站点，已有不同值仍拒绝擅自覆盖。成功排名恢复“内容、次数、排名”三列及连续并列名次。

全量缓存仍严格要求成功率大于85%，等于85%也不更新。定点成功不使用全量85%门禁，失败不撤销旧缓存；缓存失败或冲突只报告，不把旧缓存当成本轮实时结果。整批成功缓存一次调用批量更新函数，避免逐站复制整份缓存。

## 来源与边界

共识取源任何一次明确同期冲突都失败；下一期存在性独立于首尾位置验证。保留既有站点的年度/记录周期隔离，不跨来源借锚点。

列表第一页只有较新期也继续同栏目顺序翻页，扫描到全部更旧期停止，10页上限在下一次请求前检查。详情补齐已配置嵌入文档后才标记完成。锚点解析先确定真实终点，再限制窗口不能跨停止行或下一栏目。过滤后无有效候选返回明确边界失败。

浏览器接口根据正文记录自己的ID投影唯一文章；其他记录和嵌套推荐不能借用目标ID。用户列表仅保留该用户自己的记录，仍交由现有专属解析器锁定指定期帖子。证据回执增加 `api_url`，候选与文档均有记录ID时必须一致，原始行不能超出声明区块。

HTTPS证书失败不再重试 `verify=False`。此前依赖无证书校验的站点会明确失败，需要正确证书或可信CA；本次没有更改站点地址或伪造验证成功。动态文章派生API全部404后先尝试HTTP正文，只有已确认空壳才允许浏览器。

同URL不等于同业务来源：保留已登记的三个三怪分栏和不同 `article_keyword` 的列表栏目，仅拒绝同一来源同字段重复配置。

## 文件写入

正式提交对实际缓存/TXT路径加跨进程锁，覆盖整个读取—合并—持久化过程；冲突时快速拒绝第二个写入任务。配置追加也加文件锁。TXT批次先写临时文件、原字节备份与恢复标记，普通替换异常回滚；硬终止留下恢复证据。发现未完成事务时拒绝继续覆盖。

恢复需明确指定错误提示中的 `.zodiac-txn-*.json`，确认没有其他写入任务后执行：

```powershell
$env:PYTHONPATH = "$PWD\src"
python -c "from pathlib import Path; from zodiac_v2.storage import recover_transaction; recover_transaction(Path(r'完整事务标记路径'))"
```

恢复前校验备份哈希，以及目标文件仍为本事务旧值或新值；有后续不同更新则拒绝覆盖。多文件系统没有瞬时多文件原子替换，本实现提供写入者互斥、异常回滚及中断恢复，不声称任意外部读取者看不到短暂替换窗口。TXT与缓存按原项目契约分别提交，缓存异常不回滚已发布实时TXT。

## 资源与验证范围

浏览器并发最多2、接口响应最多32、单接口16MB、浏览器正文和接口累计32MB，来源包累计64MB；拦截图片、字体和媒体。声明长度超过上限在读取正文前拒绝，正文读取后仍校验实际字节。缺少或错误Content-Length的响应仍可能在Playwright读取中临时占用更多内存；这不是浏览器进程硬内存限额。同步Playwright对象不跨线程共享，本轮保留按任务创建、关闭浏览器，尚未改为持久浏览器工作线程池。
