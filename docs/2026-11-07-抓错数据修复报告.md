# 抓错数据风险修复报告（2026-11-07）

## 背景

310 期前对 `杀肖-V2` 做抓错数据风险审核，复现两条高危借值路径：

1. 跨行拼接：`_line_windows` 把相邻 1–3 行拼成一段再套正则，窗口里没有换行，
   `dedicated.py` 的通用正则用 `[^\n]{0,80}` 就能跨过期号。
   例：`310期资料更新中` + `309期 绝杀一肖【牛】` → 解析成 310=牛。
2. 锚点块过宽：站名出现在侧栏/推荐位时，块一直延伸到下一条标题，
   中间他人的同期记录会被当成本站结果。

## 已实施

### P0：期号归属门禁（`validation/evidence.py`）

- 新增 `_raw_line_owns_period`：原始行里生肖之前若出现别的期号，判 `FIELD` 失败。
- 期号 token 规则：
  - `第309期` 是真实期号；只有 `第` + 数字 ≤12 的序号（如“本月第2期”）豁免；
  - 期号后紧跟字段词（杀/殺/禁/绝/絕/必/肖，含顿号逗号等分隔符）不算说明；
  - 期号前 8 字内有 `上期/往期/前期/上次/前一期/回查/参考` 才按“上期说明”豁免；
  - `连中/连准/全中/精准/命中` 无条件豁免；
  - 支持全角期号（`３１０期`）。

### P0：拼接边界（`parsers/families.py`）

- `_line_windows` 遇到下一行是记录开头（`第?N期`，可带装饰前缀）或裸期号（`310杀鸡`）即停止拼接；
- 首行为“更新中/待更新/待公布/整理中”等占位文案时不再往后拼。

### P1：锚点绑定（`parsers/common.py`、`registry.py`、`cli.py`）

- `_NAV_BOUNDARY_PATTERN` 加宽：热门推荐/相关推荐/更多推荐/推荐阅读/猜你喜欢/最新文章/相关文章/友情链接等作为块终点；
- 锚点行本身命中导航词（`推荐/排行/相关阅读`）且不含“期号 + 字段词”时，该块作废；
- 锚点行出现 ≥3 个不重叠的已知站名（站名与其别名覆盖同一段只算一个）时作废；
- 站名表由 `cli._runtime` 显式传给 `build_registry(known_names)`，并自动并入 `ANCHOR_ALIASES` 的别名。

### P1 收尾：行级归属校验（`validation/evidence.py`）

- 用原始行在文档里的偏移定位“生肖所在物理行”，避免站名等早期出现的生肖字干扰；
- 期号行与值行之间若夹了 **超过 1 行正文**，判 `FIELD` 失败；
- 表格“一格一行”的短行（≤12 字、不含句号问号）和 `document.writeln` 片段不算间距；
- 解析器显式声明 `value-line:` / `record-line:` 的候选，声明行必须真的含该生肖；
- 边界说明：这条只覆盖“期号在前、值在后”的形状；`a828797` 那类表格式借值由块边界 + 期号门禁挡住，不走这条。
- 脆弱点：单元格判定是 **12 字硬切**。某站突然出现 `field` 且 reason 为“夹了 N 行正文”时，先检查它的单元格是不是变长了。
- 已知关闭：整站 JS 拼页（每行都是 `document.write*`）的站点，行级校验实际关闭，只剩期号门禁和方向规则。

## 验证

- 全量 `pytest`：470 passed / 3 skipped。
- 449 站只读扫描（310 期）：`field` 0 条、数值变化 0、新增成功 0。
- 合成回归：`tests/test_period_span_guard.py`（25 条）、`tests/test_anchor_binding.py`（17 条）。
- 声明校验（`value-line:` / `record-line:` 真实性）：目前仅单测覆盖；受影响的 16 站（薄暮知秋、神医乌乌、Ttss 14 站）在 310/311 滚期期间无候选，真实站点验证待 312 期。若届时出现 `field` 且 reason 为「声明的值行不含生肖」，先查这 16 站，再怀疑页面。

## 已知限制（fail-closed，只会漏抓不会写错值）

1. 正文中段的裸导航词（不带期号）仍会切块或作废；
2. 2 个站名的推荐行若不带期号、也不含推荐类关键词，仍可能被当锚点；
3. 块终点仍是“下一个标题/导航/作者”，没有“下一个其他站名记录”；
4. 自建脚本不传站名表时没有锚点保护（`build_registry()` 默认空表）；
5. `310期 上期309杀鸡 …` 这类“裸期号 + 字段词”无法与记录区分，保留放行；
6. 行级校验只覆盖“期号在前、值在后”，且单元格判定是 12 字硬切；JS 拼页站点的行级校验实际关闭。
7. 期号落在生肖之后的整段拼接仍不拦（该形状靠块边界和期号门禁，不是靠行级校验）。
